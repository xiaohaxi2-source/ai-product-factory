# AI产品工厂需求说明

本机单人使用的产品开发工作台。输入一句想法或上传PRD，经过对话澄清、PRD确认、方案确认、任务拆分、隔离开发、运行检查和人工验收，交付文档与源码。

## 界面

项目名置顶；顶部生产流程和左侧导航悬停展开，移出收起，不推挤工作区。左侧是集中对话，用户消息在右侧，助手在左侧；右侧仅需求与验收、生成文件两标签。澄清支持选项、推荐和自由输入。输入区加高，无下方辅助小字。助手使用本地技术伙伴插画头像。

## 数据与确认

会话、任务、确认与文件保存在本机。后台任务支持有限重试、取消和明确续跑，已保存的版本不会丢失。文档预览/下载与源码ZIP来自已保存快照。重要确认、版本一致性与防覆盖由后端约束，生成不等于业务验收。

## 当前范围

真实生成使用已登录的本机Codex CLI和现有账号额度，不自动充值或创建云资源。检查支持macOS Python/FastAPI工程；云部署、多人登录与通用前端构建尚未接入。GitHub Pages仅发布产品展示页。
